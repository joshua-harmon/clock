# The Tzolkin Clock

A clock that also works as an ancient planetarium. Its hands and rings run counterclockwise, and it follows the Moon, the stars and the planets through the 260-day Tzolkin and the 365-day Haab, showing the patterns they make together.

Live site: https://tranquil-sunshine-5a5643.netlify.app/
